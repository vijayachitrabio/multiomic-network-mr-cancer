STUDENT REPLICATION GUIDE: INDEPENDENT PROTEOMIC MR REPLICATION
================================================================================

This guide provides step-by-step instructions for replicating the independent Mendelian Randomization (MR) analyses using public proteomic datasets (deCODE, ARIC, and OpenGWAS) to validate circulating candidate breast cancer proteins.

GitHub Repository: https://github.com/vijayachitrabio/multiomic-network-mr-cancer

HARDWARE REQUIREMENTS
--------------------------------------------------------------------------------
- OS: Mac, Linux, or Windows (with WSL/Git Bash installed, as scripts use Unix `awk` and `gzcat`/`zcat` for memory efficiency).
- RAM: Minimum 8GB (16GB highly recommended due to massive GWAS file sizes).
- Storage: At least 20-30GB of free space for downloading summary statistics.


STEP 1: CLONE THE REPOSITORY
--------------------------------------------------------------------------------
Open your command line terminal and clone the project repository from GitHub:

    git clone https://github.com/vijayachitrabio/multiomic-network-mr-cancer.git
    cd multiomic-network-mr-cancer


STEP 2: INSTALL REQUIRED R PACKAGES
--------------------------------------------------------------------------------
Open R or RStudio and ensure you have the required packages installed:

    install.packages(c("data.table", "dplyr", "ggplot2", "remotes"))
    remotes::install_github("MRCIEU/TwoSampleMR")


STEP 3: DOWNLOAD MASSIVE SUMMARY STATISTICS
--------------------------------------------------------------------------------
You will be working with large GWAS summary statistics.

1. Outcome Data (Breast Cancer):
   - Create a folder: `mkdir -p data/cancer_gwas`
   - Download the Breast Cancer summary statistics (GCST90018757) from the NHGRI-EBI GWAS Catalog.
   - Place the file in `data/cancer_gwas/Breast_GCST90018757.h.tsv.gz`.

2. Exposure Data (deCODE Proteomics):
   - The scripts expect the deCODE summary statistics to be located in a directory parallel to the project root to keep the GitHub repo clean.
   - Run: `cd .. && mkdir "SUMMARY DATA-proteins" && cd multiomic-network-mr-cancer`
   - Download the relevant deCODE protein summary statistics (e.g., FGF5, UMOD, APOE, etc.) from the deCODE genetics portal and place them into the `../SUMMARY DATA-proteins/` folder.


STEP 4: RUN THE REPLICATION SCRIPTS
--------------------------------------------------------------------------------
Run the following R scripts sequentially from the root directory of the cloned repository:

1. OpenGWAS Replication (Fetches data automatically via API):
    Rscript scripts/47_opengwas_pqtl_replication_mr.R

2. ARIC Cohort Replication:
    Rscript scripts/37_aric_pqtl_replication_mr.R

3. deCODE Massive Batch Replication (Filters via Unix streaming):
    Rscript scripts/70_decode_batch_validation_v2.R

4. Generate the Final Forest Plot:
    Rscript scripts/plot_forest.R


STEP 5: VERIFY OUTPUTS & FIGURES
--------------------------------------------------------------------------------
Once the scripts complete, verify that the following outputs have been generated in the `results/decode/` and `results/` directories:

1. Data Tables:
    - results/decode/decode_batch_mr_results_v2.csv (Contains all 14 statistical metrics for each protein)

2. Publication Figures:
    - results/decode/decode_forest_plot.png (A high-resolution forest plot of all successfully validated proteins with p < 0.05)
